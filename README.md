## Overview

BookReader is a collaborative winter-project implementation developed for **West2 Online**. The repository contains both the Java backend and the Android client of a novel-reading application.

## Project Scope

The project was designed as a full-stack mobile reading application. The two modules are kept together so the original client–server workflow can be reviewed and reproduced from a single repository.

## Getting Started

### Backend

Open `BookReader(java)` in your preferred Java IDE and inspect the project configuration before running. Local database/server settings may need to be updated for a new environment.

### Android Client

Open `BookReader(android)` with Android Studio, update the backend address to your local/server endpoint, and build the application using the Android project configuration included in the repository.
